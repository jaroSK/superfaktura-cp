# SuperFaktúra API CP

Wordpress plugin that creates estimate in SuperFaktúra with Woocommerce cart items and downloads it in pdf format. Plugin was created for www.adverti.sk.

Wordpress plugin, ktorý po kliknutí na tlačidlo Stiahnuť cenovú ponuku v košíku vytvorí v SuperFaktúre cenovú ponuku s položkami košíka a stiahne ju vo formáte pdf. Plugin bol vytvorený pre eshop www.adverti.sk.
